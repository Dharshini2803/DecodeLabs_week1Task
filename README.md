# Java Number Game

## Project Description
A simple Java-based number guessing game.

## Features
- Generates a random number between 1 and 100
- Takes user guesses
- Provides too high/too low feedback
- Counts the number of attempts

## Technologies Used
- Java
- Random class
- Scanner class
- Loops
- Conditional statements

## How to Run

javac NumberGame.java
java NumberGame
